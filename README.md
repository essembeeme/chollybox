# chollybox

An IPTV player for Android TV, built for sports, films and TV shows. It works with your own Xtream Codes subscription; no channels or content are included.

## Install

1. On your Android TV, install **Downloader** (by AFTVnews) from the Play Store.
2. Allow it to install apps: **Settings → Device Preferences → Security & restrictions → Unknown sources → Downloader → On**.
3. Open Downloader and enter this address (or the short code you were given):

   `https://github.com/essembeeme/chollybox/releases/latest/download/chollybox.apk`

4. Choose **Install**, then open chollybox and enter your provider's server, username and password.

## Updates

chollybox checks for a new version when it starts and tells you how to install it. Updates keep your sign-in and settings.

Downloads are on the [Releases](https://github.com/essembeeme/chollybox/releases) page.
